# euclid-accents

Port of rytm-mods-src `mods/0002-euclid-accents` (MrScruff; hardware-verified there). Full usage: rytm-mods-src
`docs/MANUAL.md`, section 0002.

On the euclidean page (TRIG pressed twice), Bool Operator (OP) has eight values instead of four: OR, XOR, AND, SUB as stock, then OR\*, XOR\*, AND\*, SUB\* (the same glyph with a dot). In accent mode the euclidean generator no longer decides which steps play: only the grid's trigs play, and a trig on a step where the euclidean pattern has a hit plays accented. Hand-set accents stay. Turning euclid off with FUNC held bakes the accents into the pattern; without FUNC the pattern is left as it was. Per track, saved with the pattern; on stock firmware such a track loads with euclid off.

A detour is a `jmp` site over the whole stock instructions it displaces; the stub re-emits them
as in rytm-mods. Where rytm-mods patched the address operand of a `jsr`/`lea`/`move.l #`, the
site is elemod's `keep2` (the opcode word kept, the address the mod's). A pointer in a data
table is a `ptr` site.

## Changes from rytm-mods

- Generated by `tools/port_mod.py`. The code is unchanged; each label a site names gets a
  `.globl` alias carrying the mod id on the line before it, and the stub keeps using its own
  local labels.
- rytm-mods' default build params are fixed with `.equ` (`P_...`), as its build passed them;
  claims and code its diagnostic params select are left out.
- Every section the stub had in separate caves is `.text` here, one `.run` the linker places in
  the DDR mods area.

## Test (on a unit)

1. TRIG, TRIG again for EUCLIDEAN, EUC on, turn OP fully right: OR\* .. SUB\*.
2. With OR\* and a few grid trigs, play: only grid trigs play; those on euclid hits are accented.
3. FUNC + EUC off: the accents are written into the pattern. Save, power-cycle, reload: OP keeps its accent value.

## Results so far

- Built with elekloader at d17478b and m68k-linux-gnu binutils 2.42: `.run` 1436 B,
  17 sites, 4 relocations; lint OK; links with core-ar2 0.1 and the other ports.
- Against rytm-mods-src's default build (all of its mods at their default params; "T2" below): the original stub, re-assembled
  as rytm-mods' build does, equals T2's caves byte for byte (.text 0x402cc920). Each of its 21
  labels was then disassembled in T2 and in the full build with every address named by its label: the
  instructions match.
- Every byte the full build changes in the OS is inside one of the ports' sites, every one of these sites is
  patched in T2 too, and the `bytes` sites write exactly T2's bytes.
- rytm-emu (3c4c42c), the full build (core-ar2 with all eleven ports): EUCLIDEAN page, OP turned right: OR, XOR, AND, SUB, OR\*, ... (stock stops at SUB); all 12 screens pixel-identical to T2.
- Hardware: on an Analog Rytm MKII, 2026-10-14, in the full build (core-ar2 with all eleven ports): OP's eight values, accent mode
  (only grid trigs play, those on euclid hits accented, hand-set accents kept), revert without FUNC,
  bake with FUNC + EUC off, and OP kept through save, power cycle and reload. TRK + OP stays on
  the selected track.
